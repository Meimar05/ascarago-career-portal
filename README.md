# Ascarago Career Portfolio

A responsive career portal with nine targeted resume versions, A4 PDF downloads, interview preparation, and cover letter templates.

The public website lives in `site/`. GitHub Actions publishes that folder to GitHub Pages on every push to `main`.

This public edition omits private email, phone number, street address, birth date, and contact-inclusive PDFs. The contact toggle in the original private website only controls presentation; public versions must omit private data from source files and downloadable assets too.

All employment and education content is based on the supplied resume data. Confirm ongoing employment before updating dates. No specialist software expertise, certifications, or quantified accomplishments are claimed.
